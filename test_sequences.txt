# Тестовые последовательности для проверки тестами NIST

## Последовательность 1 (C++ mt19937)
Сгенерирована с помощью C++ std::mt19937 с распределением Бернулли
Длина: 1000000 бит
Файл: part1/random_sequence.txt

Результаты тестов:
- Частотный побитовый тест: p-value = 0.0648922
- Тест на одинаковые подряд идущие биты: p-value = 0.757011
- Тест на самую длинную последовательность единиц: p-value = 0.97

## Последовательность 2 (Java Random)
Сгенерирована с помощью Java java.util.Random
Длина: 1000000 бит
Файл: part2/random_sequence_java.txt

Результаты тестов:
- Частотный побитовый тест: p-value = 0.25512049970390693
- Тест на одинаковые подряд идущие биты: p-value = 0.020628918511920995
- Тест на самую длинную последовательность единиц: p-value = 0.4675741117197919

## Анализ результатов
Обе последовательности прошли все тесты NIST (p-value > 0.01), что подтверждает их случайность.
Тесты выполнены с помощью Python-реализации (nist_tests.py).
