# Отчет по лабораторной работе №2
## "Статистический анализ псевдослучайных последовательностей"

### Цель работы
Изучение методов генерации случайных значений и проверки сгенерированных последовательностей на случайность на основе тестов NIST.

### Выполненные задачи
1. Реализованы генераторы псевдослучайных последовательностей на языках C++ и Java
2. Реализованы три теста NIST:
   - Частотный побитовый тест
   - Тест на одинаковые подряд идущие биты
   - Тест на самую длинную последовательность единиц в блоке
3. Проведено тестирование сгенерированных последовательностей

### Описание реализации

#### Генерация псевдослучайных последовательностей
Для генерации псевдослучайных последовательностей были использованы:
- В C++: стандартный генератор `mt19937` из библиотеки `<random>`
- В Java: класс `Random` из пакета `java.util`

Длина генерируемой последовательности составляет 1 миллион бит. Последовательности сохраняются в файлы:
- `random_sequence.txt` (C++)
- `random_sequence_java.txt` (Java)

#### Реализация тестов NIST

1. **Частотный побитовый тест**
   - Проверяет, насколько часто встречаются единицы и нули в последовательности
   - Вычисляется сумма S = (количество единиц - количество нулей) / sqrt(n)
   - P-value вычисляется с использованием функции erfc

2. **Тест на одинаковые подряд идущие биты**
   - Проверяет, насколько часто меняются значения битов в последовательности
   - Вычисляется количество переходов между значениями
   - P-value вычисляется с использованием функции erfc

3. **Тест на самую длинную последовательность единиц в блоке**
   - Последовательность разбивается на блоки по 128 бит
   - Для каждого блока находится максимальная длина последовательности единиц
   - Результаты сравниваются с ожидаемым распределением

### Выводы
1. Генераторы C++ и Java показали хорошие результаты в тестах NIST:
   - Все p-value оказались выше порогового значения 0.01, что говорит о хорошем качестве генерации
   - Частотный тест (C++: p = 0.0649, Java: p = 0.2551) показывает, что распределение нулей и единиц достаточно равномерно
   - Тест на подряд идущие биты (C++: p = 0.757, Java: p = 0.0206) указывает на хорошее чередование значений
   - Тест на длину последовательностей единиц (C++: p = 0.97, Java: p = 0.4676) подтверждает отсутствие аномально длинных серий
2. Реализованные тесты позволяют эффективно оценивать качество псевдослучайных последовательностей
3. Стандартные генераторы C++ (mt19937) и Java (java.util.Random) демонстрируют высокое качество генерации случайных чисел
