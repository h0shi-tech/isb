# Гибридная криптосистема (RSA + SEED)

Данный проект реализует гибридную криптосистему, сочетающую асимметричный алгоритм RSA и симметричный алгоритм SEED.

### Криптостойкость:
- Размер блока: 128 бит
- Размер ключа: 128 бит
- Использует 16 раундов шифрования
- Считается криптостойким алгоритмом
- Прошел криптоанализ и не имеет известных эффективных атак

### Уязвимости:
- Теоретически уязвим к атакам по времени (timing attacks)
- При неправильной реализации может быть уязвим к атакам по побочным каналам
- Требует правильной реализации режима работы (CBC в данном случае)


### Генерация ключей
```bash
python hybrid_crypto.py -gen -sk symmetric_key.bin -pub public_key.pem -priv private_key.pem
```

### Шифрование файла
```bash
python hybrid_crypto.py -enc -in input.txt -out encrypted.bin -priv private_key.pem -sk symmetric_key.bin
```

### Дешифрование файла
```bash
python hybrid_crypto.py -dec -in encrypted.bin -out decrypted.txt -priv private_key.pem -sk symmetric_key.bin
```

### Режим генерации ключей (-gen):
- `-sk, --symmetric-key`: путь для сохранения зашифрованного симметричного ключа
- `-pub, --public-key`: путь для сохранения открытого ключа
- `-priv, --private-key`: путь для сохранения закрытого ключа

### Режим шифрования (-enc):
- `-in, --input`: путь к входному файлу
- `-out, --output`: путь для сохранения зашифрованного файла
- `-priv, --private-key`: путь к закрытому ключу
- `-sk, --symmetric-key`: путь к зашифрованному симметричному ключу

### Режим дешифрования (-dec):
- `-in, --input`: путь к зашифрованному файлу
- `-out, --output`: путь для сохранения расшифрованного файла
- `-priv, --private-key`: путь к закрытому ключу
- `-sk, --symmetric-key`: путь к зашифрованному симметричному ключу
